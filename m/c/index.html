① 回验：用定出的 c 去预测每一条数据

把 c 的范围代回模型，逐条算出「应该能折几次」，和实测对照。全部对得上，c 才是可信的。

② c 的数值是否合理

c 把折痕的贴合程度打包进去了，正常情况下是一个 1 量级的数——不该是 20，也不该是 0.01。
